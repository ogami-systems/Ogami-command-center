# Memory

Plain files Michael can read and edit directly — not a database blob. Saint
reads these for context; nothing here is auto-generated without review.

Suggested files as they get created (none exist yet):

- `preferences.md` — standing preferences (communication style, scheduling
  habits, recurring commitments).
- `people.md` — names, relationships, and context Saint should remember about
  people Michael interacts with regularly.

Add files here as needed. There's no fixed schema — keep them short and
human-readable.
